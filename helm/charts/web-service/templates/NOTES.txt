{{ .Chart.Name }} has been deployed!

Release: {{ .Release.Name }}
Namespace: {{ .Release.Namespace }}

1. Verify pods are running:
   kubectl -n {{ .Release.Namespace }} get pods -l "app.kubernetes.io/instance={{ .Release.Name }}"

2. Check rollout status:
   kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "web-service.fullname" . }}

3. Get the service URL:
{{- if .Values.ingress.enabled }}
   kubectl -n {{ .Release.Namespace }} get ingress
   Host: {{ (index .Values.ingress.hosts 0).host }}
{{- else }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "web-service.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
   Then open http://127.0.0.1:{{ .Values.service.port }}
{{- end }}

4. View logs:
   kubectl -n {{ .Release.Namespace }} logs -l "app.kubernetes.io/instance={{ .Release.Name }}" --tail=50

To rollback:
   helm rollback {{ .Release.Name }} <REVISION> -n {{ .Release.Namespace }}
